# Swe19centOCR
This repo contains code developed for our Master's thesis "Vision Language Model Based Systems for Optical Character Recognition of Historical Swedish Newspaper Material".
Check out our models at https://huggingface.co/J0hanski/Swe19centOCR-8B and https://huggingface.co/J0hanski/Swe19centOCR-2B, and our thesis at https://odr.chalmers.se/items/7ca2200d-24b8-4de4-a2c9-9a75e095a017.
