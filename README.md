# Swe19centOCR
This repo contains code developed for our Master's thesis "Vision Language Model Based Systems for Optical Character Recognition of Historical Swedish Newspaper Material".
Check out the models at (huggingface.co/J0hanski/Swe19centOCR-8B)[https://huggingface.co/J0hanski/Swe19centOCR-8B] and (huggingface.co/J0hanski/Swe19centOCR-8B)[https://huggingface.co/J0hanski/Swe19centOCR-8B].
